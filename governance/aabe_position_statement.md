## 一、6 條立場紅線(明確版)

1. **支持** 兩公約原始普世人權精神(生命、自由、平等、健康、教育、勞動、宗教)。
2. **反對** 將兩公約曲解為單一議程(特別是 LGBTQ+ 運動 / 同婚 / 性別認同自我認定)之法律憑藉 — 此類擴張詮釋常超出公約原文與起草史。
3. **反對** 特定政黨 / 倡議聯盟將結論性意見(CO)選擇性援引,作為自身政策合法化工具。
4. **客觀證據優先**:所有指控必須附條文號 + 官方文件出處 + 時間戳。本平台自身亦受此紀律約束 — 不以「我有立場」當免責,而以證據說話。
5. **§18 與 §26 並重**:思想良心宗教自由(§18)與不歧視(§26)為同位階條文,前者之核心(forum internum)不可被後者吞沒。ICESCR §13-3 父母教育選擇權同屬核心保障。
6. **對事不對人**:批判政策操作與擴張詮釋,不點名個別當事人人格。

## 二、核心倡議方向:「公約推動過快造成反效果」

AABE 之核心觀察 — 台灣在兩公約若干議題上**推動速度超前社會共識**,反而造成反效果(backfire):

### 2.1 同婚議題
- 2017 釋字 748 → 2018 公投 11/12 案明確反對(同志教育、民法婚姻定義)→ 2019 立法院以《748 施行法》形式強推。
- backfire:公投民意被立法覆蓋,反同 / 挺同雙方均不滿(換湯不換藥 vs 違反公投),社會撕裂未癒合。

### 2.2 性平教育
- 108 課綱推動多元性別教材,但缺乏父母 §13-3 opt-out 機制。
- backfire:Mahmoud v Taylor (605 U.S., 2025-06-27, 6-3) 國際逆向 — 美國最高法院確立父母 opt-out 為基本權利;台灣方向與國際保守化趨勢背離。

### 2.3 廢死議題
- ICCPR §6 + 4 屆 CO 連續要求廢死,但民調 88% 反對。
- backfire:113 憲判 8 號(2024)實質縮限但未廢,顯示「以 CO 強推而未先建立社會共識」之對話失敗;被害人家屬權益被邊緣化。

### 2.4 對照:傳統議題之 16 年停滯
- 集會遊行許可制:CO 第 1/2/3 屆連續要求廢除,16 年 0 進展。
- 對比同婚 2 年快速立法 → 顯示推進速度之**選擇性**:進步派議題快、保守 / 程序議題慢。

### 2.5 方法論立場(防止淪為單面武器)
- 上述觀察必須以 backfire 因果鏈(含 counter_evidence)呈現,而非斷言。
- 必須跑三公約對照組(CRC / CEDAW / CRPD):只有當兩公約之偏差 > 三對照組中位數時,才能下「兩公約被特別工具化」結論。
- 每個 backfire 鏈須標示並列原因(multi_causal_note),避免單一歸因。
