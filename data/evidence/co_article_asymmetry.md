> Wave 158 — 純客觀數據呈現,不下價值判斷結論
> 資料來源:`data/two_cov.db` → `concluding_observation` 表 (4 屆共 80 筆 CO)
> 統計基準日:2026-06-01
> 查詢方式:`article_referenced` (JSON array) LIKE 比對 + `topic` 欄位歸類

本文件統計四屆兩公約國家報告審查結論性意見 (CO) 中,各公約條文之出現頻率與議題分布,
用以檢視不同人權議題在審查機制中受關注程度之差異。所有數字均可由附錄 SQL 重現。

## 二、§18 (宗教自由) 之議題窄化情形

統計方式:逐一檢視 2 筆引用 ICCPR §18 之 CO 其 `chinese_title` 與 `recommendation_full`。

| co_id | 屆次 | CO 標題 | 議題內容 |
|---|---|---|---|
| CO-1-50 | 第 1 屆 (2013) | 良心拒服兵役 | 替代役制度 |
| CO-3-85 | 第 3 屆 (2022) | 良心拒服兵役與替代役 | 替代役制度認定範圍 |

**窄化數據**:
- 引用 §18 之 CO 共 **2 筆**,**100% (2/2)** 聚焦於「良心拒服兵役 / 替代役」單一議題。
- §18 之其他保障面向 (§18-4 父母依信仰確保子女宗教道德教育、宗教團體自主、
  信仰群體在公共與教育領域之表達) 在 4 屆 80 筆 CO 中之 `article_referenced` 欄位 **出現次數為 0**。
- 第 2 屆 (2016/2017) 與第 4 屆 (2026,預備) 之 CO **未引用 §18** (出現次數 0)。
  即 §18 僅於第 1、3 屆各出現 1 次,且兩次均為替代役。

## 三、backfire 議題 vs 傳統議題之 CO 段次數對照

「backfire 議題」指本平台界定之「快速推動 → 民意覆蓋 → 反效果」相關議題;
「傳統議題」指長期由民間倡議、推進相對停滯之公民政治權議題。
統計方式:依 `topic` 欄位歸類計數。

### A. backfire 議題群

| topic | CO 段次數 | co_id (各屆) |
|---|---|---|
| 廢死 | **4** | CO-1-39 / CO-2-36 / CO-3-41 / CO-4-3 |
| 性傾向 / SOGIE (含同婚) | **3** | CO-1-79 / CO-2-72 / CO-3-82 |
| 性別平等 (含性平教育) | **3** | CO-1-19 / CO-2-25 / CO-3-26 |
| **backfire 小計** | **10** | — |

### B. 傳統議題群

| topic | CO 段次數 | co_id (各屆) |
|---|---|---|
| 集會結社 (§21) | **4** | CO-1-52 / CO-2-49 / CO-3-57 / CO-4-6 |
| 言論自由 (§19) | **3** | CO-1-49 / CO-2-46 / CO-3-53 |
| 宗教自由 (§18) | **2** | CO-1-50 / CO-3-85 |
| 父母教育選擇權 (歸於教育權 §ICESCR-13) | **0**（無獨立 CO 段；散見教育權 3 段:CO-1-66 / CO-2-60 / CO-3-69，內容為普及/弱勢/反偏見，未直接處理父母選擇權） |
| **傳統議題小計 (§18+§19+§21)** | **9** | — |

### C. 對照數據摘要

| 指標 | backfire 議題群 | 傳統議題群 (§18/§19/§21) |
|---|---|---|
| CO 段總數 | 10 | 9 |
| 涵蓋屆次 | 廢死跨 4 屆;SOGIE/性平跨 3 屆 | 集會跨 4 屆;言論跨 3 屆;宗教跨 2 屆 (僅替代役) |
| 單一議題窄化 | 否 (各議題內含多面向) | §18 是 (100% 替代役) |
| 父母教育選擇權之獨立 CO 段 | — | 0 |

**觀察數據**:
- 廢死議題 (4 段) 在 4 屆中段次最多且連續;SOGIE/同婚 (3 段) 自第 1 屆即出現。
- 傳統議題中,集會自由 (§21) 同樣達 4 段且跨 4 屆,但宗教自由 (§18) 僅 2 段且窄化至替代役。
- 「父母教育選擇權」(AABE 等團體長期主張之 §18-4 / ICESCR §13 議題) 在 80 筆 CO 中
  **無任何獨立段次**;教育權 3 段 (CO-1-66 / CO-2-60 / CO-3-69) 之內容為教育普及、
  弱勢學生機會、教育中歧視與偏見,均未直接處理父母依信仰之課程選擇權。

## 四、§26 (不歧視) 之議題分布

統計方式:6 筆引用 §26 之 CO 其主題分布。

| co_id | 屆次 | CO 標題 | 議題領域 |
|---|---|---|---|
| CO-1-19 | 第 1 屆 | 性別歧視與暴力 | 性別 |
| CO-1-31 | 第 1 屆 | 身心障礙者人權公約之實施 | 障礙 |
| CO-1-79 | 第 1 屆 | 性傾向、性別認同之歧視 | SOGIE |
| CO-2-25 | 第 2 屆 | 婦女政治參與及職場性別歧視 | 性別 |
| CO-2-72 | 第 2 屆 | 同性伴侶法律保障 | SOGIE |
| CO-3-82 | 第 3 屆 | 同性婚姻與跨國婚姻 | SOGIE |

**分布數據**:§26 之 6 筆 CO 中,**3 筆 (50%)** 涉性傾向/性別認同 (SOGIE),
2 筆涉性別 (婦女),1 筆涉障礙。§26 不歧視原則之 CO 適用以性別與 SOGIE 議題為主要載體。

## 附錄:可重現 SQL

```sql
-- 一、§18/§26/§19/§21 出現次數
SELECT 'ICCPR-18' a, COUNT(*) FROM concluding_observation WHERE article_referenced LIKE '%ICCPR-18%'
UNION ALL SELECT 'ICCPR-19', COUNT(*) FROM concluding_observation WHERE article_referenced LIKE '%ICCPR-19%'
UNION ALL SELECT 'ICCPR-21', COUNT(*) FROM concluding_observation WHERE article_referenced LIKE '%ICCPR-21%'
UNION ALL SELECT 'ICCPR-26', COUNT(*) FROM concluding_observation WHERE article_referenced LIKE '%ICCPR-26%';

-- 二、§18 窄化檢視
SELECT co_id, review, chinese_title FROM concluding_observation
WHERE article_referenced LIKE '%ICCPR-18%' ORDER BY review;

-- 三、backfire vs 傳統議題 CO 段數
SELECT topic, COUNT(*) FROM concluding_observation
WHERE topic IN ('廢死','性傾向/SOGIE','性別平等','集會結社','言論自由','宗教自由','教育權')
GROUP BY topic ORDER BY COUNT(*) DESC;

-- 四、全 ICCPR 條文出現次數 tally
-- (於 shell 執行:取 article_referenced 拆解後 grep ICCPR | sort | uniq -c)
SELECT article_referenced FROM concluding_observation WHERE article_referenced IS NOT NULL;
```
